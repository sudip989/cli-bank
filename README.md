# CLI Bank

*Command Line Interface - Bank*


## Features
- Create bank accounts
- Deposit amount
- Withdraw amount
- Transfer amount b/w accounts
- Check balance
- List all accounts
- Store account details in a file
- Store every transaction in a file
- Logging

# Code Requirement
- Use OPPs
- Use JSON
- Use UUID to get Unique IDs
- Exception Handling
- Proper Project Structure
